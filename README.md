# H-Lab — Hai Duong Nguyen

Recruiter-first personal portfolio for an applied AI engineer, published as a GitHub Pages project site.

## Run

Open `index.html` directly, or serve the directory with any static HTTP server. No build step or runtime dependencies.

## Publish

Live website: **https://hcu-lab.me/h-lab-portfolio/**. GitHub Pages publishes the root of `main`; this project URL uses the account's existing custom domain. Assets are relative so the site works on the project subpath. The existing `Hiroshimeow.github.io` repository and its homepage remain unchanged.

## Content

Profile content is grounded in publicly linked repositories and the published research DOI. Diagrams and project visuals are original CSS/SVG illustrations, **not screenshots** of the underlying applications. This is a curated portfolio, not a source-code aggregation.

## QA

Use `node --check script.js`, `node test.js`, and `git diff --check`. `test.js` checks document structure, local asset paths, reference links and core responsive/accessibility CSS contracts. Desktop and mobile browser viewport QA is performed locally; generated screenshots are intentionally not checked into the repository.
