# H-Lab — Hai Duong Nguyen

Recruiter-first personal portfolio for an applied AI engineer, published as a GitHub Pages project site.

## Run

Open `index.html` directly, or serve the directory with any static HTTP server. No build step or runtime dependencies.

## Publish

GitHub Pages serves the root of `main` under `https://hiroshimeow.github.io/h-lab-portfolio/`. All site assets are relative so project subpaths work. The existing `Hiroshimeow.github.io` repository and custom domain are not touched.

## Content

Source facts and editorial scope: [BRIEF.md](./BRIEF.md). Links point to the public projects and the DOI; diagrams and project visuals are original CSS/SVG illustrations, **not screenshots** of the underlying applications.

## QA

Use `node --check script.js`, `node test.js`, and `git diff --check`. `test.js` checks document structure, local asset paths, reference links and core responsive/accessibility CSS contracts. Browser viewport QA is performed separately and recorded in release notes.
